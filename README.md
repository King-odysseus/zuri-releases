# Zuri desktop installers

Built binaries only. The application source lives in a private repository.

Each release holds the installers the website links to:

- `Zuri-<version>-Setup.exe` - Windows 10 or 11, 64-bit
- `Zuri-<version>.dmg` - macOS 12 or later, when one has been built

Download the newest build from the releases page, or straight from https://zuricloud-production.up.railway.app
